# To-Do List...

A simple console-based To-Do List application built with C# and .NET.

I created this project to practise C# programming and learn how to work with lists, user input and basic error handling.

## Features

- Add new tasks
- View all tasks in a numbered list
- Remove tasks by selecting their number
- Prevent empty tasks from being added
- Handle invalid menu options and task numbers
- Navigate through a simple console menu

## Technologies

- C#
- .NET
- `List<string>`

## Getting Started

Make sure you have the .NET SDK installed.

Clone the repository:

```bash
git clone https://github.com/Hossain-Al-Hejami/ToDoList.git
```

Navigate to the project folder:

```bash
cd ToDoList
```

Run the application:

```bash
dotnet run
```

## Example

```text
=== To-Do List ===
```
